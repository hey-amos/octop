# 跟进上游 1.0.3b4

- 日期：2026-11-09（Asia/Shanghai）。
- 状态：本地集成，尚未推送或发布。
- 旧上游基线：`v1.0.2`，`dd9dce470844c25d59effb50615bb3c667ea25cd`。

## 背景与范围

将 `develop` 的四个定制提交迁移到新的上游基线。保留上游新增的登录、浏览器启用、桌面权限和主动关心等流程，同时继续使用师伴品牌素材与文案。上游新增的路径前缀支持用于品牌资源和 PWA 启动路径。

上游已将通用助手模板从内置目录迁至专家市场，旧的本地模板不再恢复。默认创建 `general-assistant` 时，在保留市场模板内容和加载流程的基础上设置「师小智」名称、品牌颜色及头像；选择其他模板时仍沿用其原有信息。已有助手数据不做批量修改。

## 验证结果

- `make all` 的格式化、Ruff 和 mypy 通过；非 live 全量测试在沙箱中为 5380 项通过、40 项跳过、6 项失败、15 项报错。失败项需要本机监听端口或测试域名解析；解除对应限制后，21 项全部复测通过。全量命令本身未获得一次完整通过的结果。
- 默认助手、初始化、邀请和本地化相关后端检查 104 项通过；fork 的下载与网络探测回归检查 19 项通过。
- 前端类型检查、ESLint（无错误，72 条警告）和 18 项登录、导航、启动主题及资源路径测试通过。
- 使用模拟接口检查桌面浅色和移动端深色登录页；品牌图片可加载、移动端无水平溢出。检查 PWA 清单在根路径与子路径下的启动地址、范围及图标路径。

## 后续同步注意事项

- 市场端模板的展示名称和内容由上游市场提供；本地定制针对自动创建的默认助手，不修改市场数据。
- 沿用上游市场加载行为：市场不可用且本地没有缓存时，默认助手的自动创建会跳过；不会回退到旧内置模板。
- 继续检查品牌素材与上游资源路径、PWA 配置及登录和设置界面的合并结果。
